# Inactive plugins

Plugins here take no new installs. A plugin moves here from `catalog/active/` when:

- it's retired, because its maker stopped work on it or we decommissioned it,
- its maker asks us to pull it, or
- it's blocked for a security hole or another serious problem.

We move the file. Copies people already have keep running, unless a version is harmful.

A harmful version is also blocked. HolyArrs then refuses to install it and switches off running copies within 6 hours.
